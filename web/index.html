非官方 Flatpak 打包

在任何支持 Flatpak 的 Linux 上使用 Claude Desktop

Anthropic 只提供 .deb 安装包。这个项目把它重新打成 Flatpak,放进一个自动更新的软件源,让 Fedora Atomic、Bazzite、SteamOS 等系统也能直接安装。

下载 .flatpakref 用命令行安装 离线包

目前仅提供 x86_64。本项目与 Anthropic 没有隶属关系。

安装

添加软件源后,Claude 会随 flatpak update 一起更新。

shell 
flatpak remote-add --if-not-exists claude https://jhuang6451.github.io/flatpak-claude-desktop/claude.flatpakrepo
flatpak install claude com.anthropic.Claude
flatpak run com.anthropic.Claude

应用的 Runtime 来自 Flathub。如果系统还没有启用 Flathub,先执行 flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo。用 .flatpakref 安装时,Flathub 的地址已经包含在文件里。

软件源已用 GPG 签名,.flatpakrepo 和 .flatpakref 内嵌了公钥,Flatpak 会自动校验。签名密钥指纹:6176 AE45 DD3A 94D2 5ACB D8BD 128B 2D5D 4D43 0E28。如果你在启用签名之前添加过 claude 软件源,请先执行 flatpak remote-delete claude 再重新添加。

打包内容

程序本体与官方 .deb 一致。构建时从 Anthropic 的 APT 源下载,核对清单里记录的 SHA-256,再原样解包。

官方来源

下载地址和哈希写在清单中,每次版本变化都会随提交更新,可以在仓库里逐条核对。

自动跟进

GitHub Actions 每 6 小时读取一次官方索引,发现新版本就更新清单、构建并发布。

Wayland

在 Wayland 会话中自动启用 Ozone 和窗口装饰。可以通过配置文件追加 Electron 参数。

密钥环

登录状态保存在 GNOME Keyring 或 KDE Wallet 中,重启后不需要重新登录。

使用宿主系统上的 MCP Server

沙箱里没有 npx、uvx 或 docker。在 ~/.var/app/com.anthropic.Claude/config/Claude/claude_desktop_config.json 里用 flatpak-spawn --host 启动宿主上的程序:

json
{
  "mcpServers": {
    "filesystem": {
      "command": "flatpak-spawn",
      "args": [
        "--host", "npx", "-y",
        "@modelcontextprotocol/server-filesystem",
        "/path/to/allowed/directory"
      ]
    }
  }
}

权限

这个 Flatpak 的沙箱隔离很弱。应用可以读写整个用户目录,还能通过 flatpak-spawn --host 在宿主系统运行任意命令,实际权限等同于当前用户。保留这两项是为了支持宿主 MCP Server 和任意项目目录。

权限用途
--filesystem=home读写用户目录
--talk-name=org.freedesktop.Flatpak在宿主系统运行命令
--share=network访问 Claude 服务和 MCP Server
--device=dri、--device=kvmGPU 加速、Cowork 本地虚拟机
Wayland、X11、PulseAudio、PipeWire显示与音频
通知、托盘、全局菜单、密钥环桌面集成与登录状态保存

不需要宿主 MCP 时,可以用 Flatseal 或下面的命令撤销:

shell
flatpak override --user --nofilesystem=home com.anthropic.Claude
flatpak override --user --no-talk-name=org.freedesktop.Flatpak com.anthropic.Claude

已知限制

  • 仅 x86_64。清单保留了 aarch64 的下载源,但持续集成不构建它。
  • GNOME 搜索提供器不可用。上游实现依赖宿主的 gjs,无法在沙箱内注册。
  • Claude in Chrome 需要手动配置。运行仓库里的 scripts/install-chrome-native-host.sh,再重启应用和浏览器。Flatpak 版浏览器暂不支持。
  • Cowork 需要 KVM。宿主没有 /dev/kvm 时,本地虚拟机无法启动,其余功能不受影响。

更新方式

每次发布都会从空仓库重新构建,软件源里只保留最新提交。OSTree 按文件内容寻址,客户端只下载本地没有的对象,但不提供从旧版本出发的增量包。
