Unofficial Flatpak package

Claude Desktop on any Linux with Flatpak

Anthropic ships only a .deb package. This project repackages it as a Flatpak and hosts it in an automatically updated repository, so Fedora Atomic, Bazzite, SteamOS, and similar systems can install it directly.

Download .flatpakref Install from the command line Offline bundle

x86_64 only for now. This project is not affiliated with Anthropic.

Install

Once the remote is added, Claude updates with flatpak update.

shell 
flatpak remote-add --if-not-exists claude https://jhuang6451.github.io/flatpak-claude-desktop/claude.flatpakrepo
flatpak install claude com.anthropic.Claude
flatpak run com.anthropic.Claude

The runtime comes from Flathub. If Flathub isn't enabled yet, run flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepofirst. Installing from the .flatpakref works without this step because the file includes the Flathub URL.

The repository is signed with GPG. .flatpakrepo and .flatpakref embed the public key, and Flatpak verifies signatures automatically. Key fingerprint: 6176 AE45 DD3A 94D2 5ACB D8BD 128B 2D5D 4D43 0E28. If you added the claude remote before signing was enabled, run flatpak remote-delete claude and add it again.

What's in the package

The program is identical to the official .deb. The build downloads it from Anthropic's APT repository, checks the SHA-256 recorded in the manifest, and unpacks it as is.

Official source

The download URL and hash are in the manifest and change with each version commit, so you can check them in the repository.

Automatic updates

GitHub Actions reads the official index every 6 hours. When a new version appears, it updates the manifest, builds, and publishes.

Wayland

Wayland sessions get Ozone and window decorations automatically. A config file can add Electron flags.

Keyring

Login state is stored in GNOME Keyring or KDE Wallet, so you stay signed in across restarts.

MCP servers on the host

The sandbox has no npx, uvx, or docker. In ~/.var/app/com.anthropic.Claude/config/Claude/claude_desktop_config.json, start host programs with flatpak-spawn --host:

json
{
  "mcpServers": {
    "filesystem": {
      "command": "flatpak-spawn",
      "args": [
        "--host", "npx", "-y",
        "@modelcontextprotocol/server-filesystem",
        "/path/to/allowed/directory"
      ]
    }
  }
}

Permissions

This Flatpak has weak sandbox isolation. The app can read and write your whole home directory and run arbitrary commands on the host through flatpak-spawn --host, so it effectively has the current user's privileges. Both permissions stay to support host MCP servers and arbitrary project directories.

PermissionPurpose
--filesystem=homeRead and write the home directory
--talk-name=org.freedesktop.FlatpakRun commands on the host
--share=networkClaude services and MCP servers
--device=dri、--device=kvmGPU acceleration, Cowork local virtual machine
Wayland, X11, PulseAudio, PipeWireDisplay and audio
Notifications, tray, global menu, keyringDesktop integration and login storage

If you don't need host MCP servers, revoke them with Flatseal or these commands:

shell
flatpak override --user --nofilesystem=home com.anthropic.Claude
flatpak override --user --no-talk-name=org.freedesktop.Flatpak com.anthropic.Claude

Known limitations

  • x86_64 only. The manifest keeps an aarch64 download source, but CI doesn't build it.
  • No GNOME search provider. The upstream implementation needs gjs on the host and can't register from inside the sandbox.
  • Claude in Chrome needs manual setup. Run scripts/install-chrome-native-host.sh from the repository, then restart the app and the browser. Flatpak builds of browsers aren't supported yet.
  • Cowork needs KVM. Without /dev/kvm on the host, the local virtual machine can't start. Everything else works.

How updates work

Each release is built from an empty repository, so the remote keeps only the latest commit. OSTree addresses files by content and clients download only the objects they lack, but there are no deltas from older versions.
