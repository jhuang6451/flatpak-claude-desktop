Anthropic Claude Desktop

官方 Claude AI Linux 桌面客户端。内置 Model Context Protocol (MCP) 与本地隔离沙箱支持，优化 Wayland 缩放与密钥环集成，开箱即用。

一键安装 (.flatpakref) 终端命令安装 离线 Bundle 下载

终端快速安装（推荐）

添加此 Flatpak 软件源后，即可享受系统原生的软件包管理与后台自动增量升级：

BASH 
# 1. 添加 Claude 软件源仓库
flatpak remote-add --if-not-exists claude https://jhuang6451.github.io/flatpak-claude-desktop/claude.flatpakrepo

# 2. 安装 Claude Desktop
flatpak install -y claude com.anthropic.Claude

# 3. 运行应用
flatpak run com.anthropic.Claude
